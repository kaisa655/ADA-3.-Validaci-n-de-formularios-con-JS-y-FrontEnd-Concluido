Acerca de PublicArcade

PublicArcade es una propuesta de plataforma para compartir y descubrir videojuegos.

El proyecto busca ofrecer un espacio sencillo donde los creadores puedan presentar sus juegos mediante una descripción, una categoría, una imagen y un enlace para probarlos.

Objetivo

Crear una comunidad digital que facilite la difusión de videojuegos independientes y fomente el intercambio de creaciones.

Tecnologías utilizadas

HTML

Estructura de las páginas.

CSS

Diseño visual y adaptación a pantallas.

JavaScript

Validaciones e interactividad.

Esta versión es una demostración FrontEnd. La conexión a una base de datos y la carga real de archivos al servidor se implementarán en una etapa posterior.
